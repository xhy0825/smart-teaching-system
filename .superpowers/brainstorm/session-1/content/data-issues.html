发现的数据准确性问题

学生画像和班级画像模块中的数据计算错误

问题 1：知识点掌握率计算错误

StudentProfileService.java:130-146

  • 错误：假设每个知识点只错 1 题 (correctCount = total - 1)
  • 实际：应该根据错题记录计算正确率
  • 影响：学生画像中的知识点掌握雷达图数据不准
当前错误代码
// 假设错误数为1，正确数 = total - 1（简化逻辑）
int wrongCount = 1;  // ← 这里写死了！
int correctCount = Math.max(0, total - wrongCount);

问题 2：错题类型分布是模拟数据

StudentProfileService.java:195-210

  • 错误：直接写死选择题占50%、填空题占33.33%
  • 实际：应该从错题记录中按题型聚合统计
  • 影响：错题类型饼图显示虚假数据
当前模拟数据代码
// 错题类型分布（模拟）
choiceType.setCount(wrongQuestions.size() / 2);  // ← 写死50%
choiceType.setPercentage(BigDecimal.valueOf(50));
fillType.setCount(wrongQuestions.size() / 3);   // ← 写死33%
fillType.setPercentage(BigDecimal.valueOf(33.33));

问题 3：班级知识点掌握率计算不准确

ClassProfileService.java:124-132

  • 错误：只统计"有多少学生错了这个知识点"，而非"错误率"
  • 公式：1.0 - (wrongCount / students.size()) 不反映真实掌握率
  • 影响：班级画像中的知识点掌握表格和雷达图不准确

问题 4：N+1 查询性能问题

ClassProfileService.java:196-216

  • 问题：对每个学生循环查询答题卡（buildScoreBoxplot）
  • 影响：班级人数多时性能差
  • 注意：这是性能问题，但也影响数据准确性（可能查询超时）
