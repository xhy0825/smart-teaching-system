    • 检查是否有遗漏的字段
  • api/class-profile.ts
    • 确认 API 返回类型定义正确

4.2 数据格式验证

知识点雷达图数据格式
{
  "points": ["代数", "几何", "概率"],
  "scores": [85.5, 92.0, 78.5]
}
// scores 应该是正确率，范围 0-100
错题类型饼图数据格式
{
  "types": ["选择题", "填空题", "判断题"],
  "counts": [10, 5, 3]
}
// counts 应该是真实统计值

4.3 测试验证步骤

手动测试清单
  1. 启动后端（MySQL + Redis）
  2. 启动前端（npm run dev）
  3. 登录系统，进入"学生画像"
  4. 选择一个学生，检查：
    • 知识点掌握雷达图是否有数据
    • 错题类型饼图是否显示真实数据（非50%/33%）
    • 成绩趋势折线图是否正确
  5. 进入"班级画像"，选择一个班级，检查：
    • 基础统计（平均分、最高分等）是否正确
    • 知识点掌握表格数据是否合理
    • 雷达图和箱线图是否正常

如果后端修复后数据格式变化

  • 更新 TypeScript 接口定义
  • 调整 ECharts 配置（如果数据结构变化）
  • 添加加载状态和错误处理
