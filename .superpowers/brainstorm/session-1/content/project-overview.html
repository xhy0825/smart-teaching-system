edu 项目概览

基于 Spring Boot + Vue 3 的智能教育平台

项目规模

132 个 Java 文件

后端包含完整的分层架构

30+ Vue 组件

前端涵盖完整教学流程

15+ 数据库表

支持多租户和完整业务

技术架构

系统架构图
前端层: Vue 3 + Vite + Element Plus + ECharts
↑ Axios HTTP ↓
后端层: Spring Boot 3.2 + MyBatis-Plus + JWT
↑ JDBC ↓
数据层: MySQL 8 + Redis (可选)
← →
外部服务: Claude API (AI 批改/出题/PPT)

核心功能模块

后端模块 (Java)
  • common - JWT、安全、拦截器、全局异常
  • tenant - 多租户管理
  • user - 用户、角色、学生管理
  • exam - 题库、题目、试卷模板
  • grading - 答题卡、批改、成绩分析
  • ai - AI 服务（Claude API）
前端视图 (Vue)
  • Dashboard - 首页统计
  • QuestionBank/Question - 题库管理
  • ExamTemplate/Paper - 试卷管理
  • ExamGenerate - AI 出卷
  • Grading - 在线批改
  • ScoreAnalysis - 成绩分析
  • Student/Class Profile - 画像分析
  • PptMaker - AI 生成 PPT
