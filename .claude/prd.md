# PRD - 极简出卷+拍照批改实现

## 需求
| ID | 需求≤30字 | 验收标准 |
|----|----------|---------|
| R1 | 极简出卷：输入框+按钮生成试卷 | 1分钟内生成，成功率≥95% |
| R2 | 拍照批改：手机拍照上传+识别批改 | 准确率≥85%，<5分钟完成全班 |
| R3 | Claude API 公共调用提取 | 代码复用，便于维护 |
| R4 | Redis 对话管理 | 对话上下文持久化，24h过期 |
| R5 | 成本监控 | 每日限额$50，超支告警 |
| R6 | 边界测试+并发测试 | 45并发通过，边界条件覆盖 |

## 技术栈
- 后端：Spring Boot 3.2 + Java 17 + MyBatis-Plus
- 前端：Vue 3 + Element Plus
- AI：Claude API (Sonnet 4.6) + Vision API
- 缓存：Redis (对话管理+成本统计)

## 非功能需求
- 性能：极简出卷<5分钟，拍照批改<5分钟/班
- 准确率：拍照批改识别准确率≥85%
- 成本：每日 API 成本≤$50，自动告警
- 并发：支持 45 学生同时拍照批改

## UI 方向
- 设计系统：Glassmorphism + SaaS-Blue + Inter/Poppins
- 极简出卷：主页一个输入框+一个按钮
- 拍照批改：手机拍照→上传→批改→显示结果
- 配色：CSS Variables，支持浅色/深色模式
