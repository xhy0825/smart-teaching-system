# PRD - 修复菜单导航栏收起显示异常

## 需求
| ID | 需求≤30字 | 验收标准 |
|----|----------|---------|
| R1 | 修复菜单折叠后图标居中 | 折叠后图标垂直居中显示 |
| R2 | 隐藏折叠状态文字 | 折叠后不显示菜单文字 |
| R3 | 隐藏折叠状态箭头 | 折叠后子菜单箭头不显示 |
| R4 | 保持折叠动画流畅 | 展开/收起过渡平滑 |

## 技术栈
- Vue 3 + Element Plus
- 现有 Layout.vue 组件

## 非功能
- 兼容性: Element Plus 菜单折叠 API
- 性能: 无额外渲染开销

## UI方向
- 保持现有 Glassmorphism 设计
- 折叠后仅显示图标（64px 宽）
