# PRD - 首页Dashboard优化

## 需求
| ID | 需求≤30字 | 验收标准 |
|----|----------|---------|
| R1 | 现代数据大屏视觉风格 | 渐变背景、玻璃态卡片、数据可视化 |
| R2 | 统计卡片升级 | 4+指标、趋势箭头、玻璃态效果 |
| R3 | 数据可视化图表 | ECharts展示学科分布/成绩趋势 |
| R4 | 快捷操作区优化 | 图标+文字、悬停动效、6+入口 |
| R5 | 最近试卷列表增强 | 状态标签、时间格式化、空状态 |
| R6 | 响应式适配 | 375/768/1440px三断点正常 |
| R7 | 加载状态优化 | 骨架屏/Spinner、错误提示 |

## 技术栈
- Vue 3 + TypeScript + Element Plus
- ECharts 6.x（图表）
- 设计系统：Data-Dense Dashboard风格
  - 主色: #1E40AF、副色: #3B82F6、CTA: #F59E0B
  - 字体: Fira Code(数据) + Fira Sans(正文)
  - 效果: 玻璃态、悬停提示、平滑过渡

## 非功能
- 性能: 首屏<2s、图表渲染<500ms
- 可访问性: WCAG AA、对比度≥4.5:1
- 兼容性: Chrome/Edge最新版

## UI方向
- 风格: 数据密集仪表盘、最大数据可见性
- 布局: 统计卡片(上) → 图表(中) → 列表+操作(下)
- 动效: 150-300ms过渡、悬停缩放、加载骨架屏
